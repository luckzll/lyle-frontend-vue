# Lyle Frontend V6.2

- Replaced the persistent image-upload and resend controls with a single attachment-aware composer.
- Added image/file picker, page-level drag and drop, clipboard image paste, per-item validation, retry, removal, and upload status.
- Added structured message attachments, authenticated attachment rendering, generated-image preview/download, and failure-local retry actions.
- Preserved V6.1 URL-based image history as a read-only compatibility path.
- Added V6.2 desktop/mobile Playwright coverage and structured-history unit coverage.

Third-party UI icons continue to come from the existing `@lucide/vue` dependency (Lucide, ISC). No external screenshots, logos, or copied chat components were added.
