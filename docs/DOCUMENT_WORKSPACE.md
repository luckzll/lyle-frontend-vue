# 聊天内文档工作区

2026-11-01。沿用现有 ChatView、模型、工具及输入框，在右侧按需展开文档。文档任务的长回复在侧栏关闭时默认折叠，卡片可打开正文草稿；并排协作时显示回复正文和草稿入口。普通问答仍显示完整回答。

## 已实现

- 新建正文、读取本地文件，或读取现有消息中的 Office / PDF 附件。解析复用带登录校验的 `/api/local-workspace/document/extract`，最大 5 MB，截断与解析提示显示在转换说明中。
- Markdown 正文编辑、预览、命名、保存版本、恢复、撤销。最多六份草稿，每份最近二十个版本。切换上下文或记忆面板保留草稿，对话之间隔离，退出账号清空；异步读取不会写回已离开的对话。
- 在原聊天输入框引用全文或选区，由所选模型返回改写。发送内容保留在聊天记录的可展开修改范围中，回复需点击应用。基准版本已改变时拒绝覆盖，可另存为新草稿。
- 生成真实 DOCX、PDF、XLSX、PPTX 或 Markdown；沿用系统选择保存位置和浏览器下载。文档顶部统一“下载”入口，展开后可选择 PDF 等格式，直接生成文件。生成库按格式延迟加载。
- 手机使用带名称的文档弹层、键盘 Tab 循环与 Escape 关闭；引用后返回原输入框。

## 当前能力边界

这是正文草稿编辑与重新生成，尚未接入 ONLYOFFICE 等完整原生 Office 引擎。原文件不被覆盖，复杂排版、图片、图表、公式、宏和动画不保留；扫描 PDF 沿用现有解析限制，不做 OCR。Excel 将竖线/制表符分列，单元格作为文字，不执行模型或文件中的公式。PPT 根据标题和正文分页为文字幻灯片，最多 150 页。AI 单次修改范围最多三万字，草稿最多二十万字。

草稿和版本仅在本页内存中保存，离开/刷新前需要下载；界面不显示“云端已保存”。上传解析会发送到本站服务，引用提问会按普通聊天进入当前模型和聊天记录。没有新建云端文件存储、权限模型或数据库迁移。

2026-11-01 增加 PDF 直接保存：浏览器后台线程生成 A4 文本 PDF，内嵌中文字体及单色符号，长表格跨页重复表头，图片保留文字说明。常用字使用预处理字体，生僻汉字按需加载完整字体。格式切换、继续编辑、关闭面板时取消旧任务。字体解压与处理均在浏览器内进行，正文不送入额外转换服务。PDF 最多 200 页、表格最多 10 列，无法支持的字符和超限内容明确报错。

## 标签式工作区

2026-11-02 根据用户提供的 Codex 侧边工作区截图更新。桌面右侧贴边停靠，默认占可用区域的 52%，文档与上下文共用相同的标签栏和宽度。聊天、文档分别滚动，输入框保留在聊天列。分隔线支持鼠标拖动、左右方向键微调、Home 或双击恢复默认比例；边界为两侧保留可读宽度。

顶部标签显示本页草稿文件名，可以切换多份草稿；新建文档位于标签栏加号。右上角支持放大 / 恢复工作区和关闭。关闭工作区不会删除本页草稿。预览、编辑、撤销、版本和下载放在紧凑工具栏；更多菜单提供重命名、读取文件和保存当前版本。正文去除外层纸张卡片，使用连贯阅读表面。文档区采用中性色，沿用应用的浅色 / 深色主题变量。

上下文按项目计划、知识库等资料组织，执行步骤默认收起，避免重复展示空状态。宽度小于等于 1100px 时使用贴边文档弹层和上下文弹层。底部字数说明可展开查看本页保存及格式转换边界，引用选区 / 全文仍进入原聊天输入框。

下载浮层在拖窄工作区后仍限制在面板宽度内，支持 Escape 收起、返回触发按钮、点击外部收起，保存位置选择期间保持打开。

## 验证

前端全量单元测试 735 项通过，新增覆盖范围修改、过期回复、恢复前未保存内容、版本上限、跨账号与对话隔离、迟到解析，以及 XLSX/PPTX 的真实文件结构。浏览器以真实 AppShell/ChatView 和隔离合成响应检查发送、应用、撤销及桌面/390px 布局；此验证不代表生产模型内容质量。Word、Excel 文件经过实际浏览器下载并核对内容。构建须从提交后的干净 worktree 执行，不包含本地未提交的 AppShell 页脚与审计修改。
