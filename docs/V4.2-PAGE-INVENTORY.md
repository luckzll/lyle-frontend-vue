# V4.2 页面清单

| 分组 | 页面 | 路由 | V4.2 主要能力 |
| --- | --- | --- | --- |
| 开始 | 今日工作台 | `/dashboard` | 今日重点、待处理、最近结果、活跃项目、快捷意图与动作 |
| 开始 | 聊天 | `/` | 任务建议、Markdown、来源、再次发送、一次性项目上下文、执行时间线、右侧上下文 |
| 推进 | 项目 | `/projects`, `/projects/:projectId` | 概览、任务、近期结果、关联自动化、携带项目 ID 发起聊天 |
| 推进 | 任务 | `/tasks` | 今天、即将到期、逾期、全部；独立动作状态和删除确认 |
| 推进 | 自动化 | `/automations` | 我的自动化优先、模板/自然语言创建、运行/暂停/恢复、设置抽屉、删除确认 |
| 推进 | 执行中心 | `/execution-center` | 待我确认、需要处理、最新结果、历史；筛选、详情、重试、复制链接 |
| 资料 | 知识库 | `/knowledge-bases` | 原有知识资料管理，接入统一壳层 |
| 资料 | 记忆 | `/memory` | 原有记忆治理，接入统一壳层 |
| 资料 | 会话 | `/conversations` | 原有会话管理，支持聊天标题持久化 |
| 系统 | 连接 | `/connections` | 健康卡、能力范围、原因、下一步、按连接独立诊断 |
| 系统 | 设置 | `/settings` | 原有设置页，接入统一壳层 |
| 系统 | 高级设置 | `/advanced-settings` | 原工作台能力与明显的高级模式提示 |
| 管理员 | 评测 / Prompt / 管理 | `/evaluation`, `/prompts`, `/admin` | 仅管理员渲染并由路由守卫校验 |

兼容规则：`/operations` 保留并重定向到 `/execution-center?view=history`；`/connectors` 保留并重定向到高级设置的连接器页签。原查询参数会一并保留。

执行中心仅在列表展示摘要，技术数据按需加载进详情抽屉。Dashboard 最多并发四组聚合请求并使用 `Promise.allSettled`，单个模块失败时其余模块仍可操作。
