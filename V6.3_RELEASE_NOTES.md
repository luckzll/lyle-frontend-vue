# Lyle Frontend V6.3.0

- Rebuilt the login entry with empty production credentials, accessible labels, password visibility, generic errors, and safe protected-route return.
- Removed the persistent attachment button and added workspace drop, paste, slash commands, and scoped keyboard pickers.
- Added bounded folder scanning, skip summaries, stable relative paths, upload metadata, and grouped draft/history rendering.
- Preserved V6.2 attachment limits, concurrency, retry behavior, and legacy history compatibility.
- Loads the versioned production TOS login ambient first, with a bundled SVG fallback and fixed dimensions.
- Mounts the login UI without waiting for optional runtime rollback configuration; public bootstrap requests no longer affect authenticated sessions.
- Runs Playwright on an isolated, feature-flagged test server by default so a developer server cannot change V5/V6 regression results.

Verification: 94 frontend unit tests and the production build pass; Playwright passes 104 tests with 8 real-stack-only tests skipped and no failures.
